Community Monero Light-Wallet Server

Welcome to this community-operated Monero light-wallet service (LWS). Connect a compatible wallet to get instant access to your Monero funds from anywhere in the world. No full node required, no blockchain sync, no waiting.

Getting Started

There are two ways to set up your wallet on this server. Pick whichever is easiest for you.

Option A: Register here first, then connect your wallet
  1. Register your wallet on this site. You will need your public address, secret view key, an email for contact, and a short label.
  2. Download the Skylight wallet (or any Monero light-wallet client).
  3. In the wallet settings, enter the connection URL below to point it at this server. Your wallet will be ready to use immediately.

Option B: Connect your wallet first, then register here
  1. Download Skylight and set the server URL to this LWS (see below).
  2. Create or restore a wallet in Skylight. The server will see the connection but will not begin scanning until you complete registration.
  3. Come back here and register your wallet with the same public address. The server will automatically activate scanning for you.

Privacy and Trust

By using this service you are sharing your secret view key with the server operator. This means the operator can see your incoming transactions, amounts, and when they occur. The operator cannot spend your funds. Only the secret spend key (which is never shared) can do that.

Make sure this trade-off fits your threat model before registering. If you need full privacy, run your own node or your own LWS instance instead.

Important Notes

  • New wallets only. This server scans from the current block height forward. Restoring wallets from genesis (block 0) is not supported. If you have an existing wallet with prior transaction history, those older transactions will not appear.
  • Registration is required. You must register through this site for your wallet to be actively scanned. Simply connecting a light-wallet client is not enough.
  • Your view key is stored on this server. The LWS daemon needs your secret view key to scan for incoming transactions on your behalf. Your spend key is never needed and should never be shared.
